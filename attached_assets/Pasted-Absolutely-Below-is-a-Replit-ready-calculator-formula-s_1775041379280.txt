RealProfits — Gold Calculator Formula Spec

Global implementation rules

Use these conventions across all calculators:

// percent helper
const pct = (value: number) => value / 100;

// monthly rate from annual %
const monthlyRate = (annualRate: number) => annualRate / 12 / 100;

// yearly to monthly
const monthlyFromAnnual = (annual: number) => annual / 12;

// standard rounding for UI only
const round2 = (n: number) => Math.round(n * 100) / 100;

General rules
	•	Store raw math in full precision
	•	Round only for display
	•	Reject negative values unless explicitly allowed
	•	If denominator is 0, return safe fallback
	•	If payment does not exceed monthly interest in amortization calculators, show warning and stop loop

1) SAVINGS CALCULATORS

1. Simple Savings Calculator

Inputs
	•	initialDeposit
	•	monthlyContribution
	•	annualInterestRate
	•	years

Formula

Monthly compounding with recurring monthly additions:

const r = annualInterestRate / 12 / 100;
const months = years * 12;

let balance = initialDeposit;
let totalContributions = initialDeposit;

for (let i = 1; i <= months; i++) {
  balance = balance * (1 + r) + monthlyContribution;
  totalContributions += monthlyContribution;
}

const interestEarned = balance - totalContributions;

Outputs
	•	endingBalance
	•	totalContributions
	•	interestEarned
	•	monthly/yearly projection array

Edge cases
	•	if rate = 0, balance = initial + contributions only
	•	if contribution = 0, grow deposit only

4. Monthly Savings Calculator

Inputs
	•	targetAmount
	•	currentSavings
	•	yearsToGoal
	•	annualInterestRate

Formula

Solve for monthly contribution by iterative search or future value annuity formula.

Recommended iterative approach for simplicity:

function requiredMonthlySavings(target, current, years, annualRate) {
  const r = annualRate / 12 / 100;
  const months = years * 12;
  let low = 0;
  let high = target;

  for (let j = 0; j < 100; j++) {
    const mid = (low + high) / 2;
    let balance = current;

    for (let i = 0; i < months; i++) {
      balance = balance * (1 + r) + mid;
    }

    if (balance >= target) high = mid;
    else low = mid;
  }

  return high;
}

Outputs
	•	requiredMonthlyContribution
	•	totalContributions
	•	projectedInterest

10. Mortgage Amortization Calculator

Inputs

Same as mortgage calculator, minus optional extras if desired.

Formula

Month-by-month loop:

let balance = loanAmount;
const schedule = [];

for (let month = 1; month <= n; month++) {
  const interest = balance * r;
  const principal = principalAndInterest - interest;
  balance = Math.max(0, balance - principal);

  schedule.push({
    month,
    payment: principalAndInterest,
    principal,
    interest,
    balance,
  });

  if (balance <= 0) break;
}

Outputs
	•	full amortization schedule
	•	yearly rollups
	•	total interest
	•	payoff date

14. Loan Affordability Calculator

Inputs
	•	grossMonthlyIncome
	•	debtToIncomeLimitPercent
	•	existingMonthlyDebt
	•	annualInterestRate
	•	loanTermMonths

Formula

const maxDebtAllowed = grossMonthlyIncome * (debtToIncomeLimitPercent / 100);
const availableForNewLoan = Math.max(0, maxDebtAllowed - existingMonthlyDebt);

Then reverse-solve loan amount from payment. Binary search is easiest:

function maxAffordableLoan(payment, annualRate, months) {
  const r = annualRate / 12 / 100;
  let low = 0;
  let high = 10000000;

  for (let i = 0; i < 100; i++) {
    const mid = (low + high) / 2;
    const monthly =
      r === 0
        ? mid / months
        : mid * (r * Math.pow(1 + r, months)) / (Math.pow(1 + r, months) - 1);

    if (monthly <= payment) low = mid;
    else high = mid;
  }

  return low;
}

Outputs
	•	maxAffordableMonthlyPayment
	•	maxLoanAmount

3) TAX CALCULATORS

16. Simple Tax Estimator

Inputs
	•	filingStatus
	•	grossIncome
	•	deductions
	•	stateTaxRate

Formula

const taxableIncome = Math.max(0, grossIncome - deductions);

Federal tax should use a simplified bracket table in code.

Example structure:

const federalBrackets = {
  single: [
    { upTo: 11600, rate: 0.10 },
    { upTo: 47150, rate: 0.12 },
    { upTo: 100525, rate: 0.22 },
    // continue
  ],
  marriedJoint: [
    { upTo: 23200, rate: 0.10 },
    { upTo: 94300, rate: 0.12 },
    { upTo: 201050, rate: 0.22 },
    // continue
  ],
};

Bracket calc:

function calcProgressiveTax(income, brackets) {
  let tax = 0;
  let prev = 0;

  for (const bracket of brackets) {
    const upper = bracket.upTo;
    const taxableAtThisRate = Math.min(income, upper) - prev;
    if (taxableAtThisRate > 0) {
      tax += taxableAtThisRate * bracket.rate;
      prev = upper;
    }
    if (income <= upper) break;
  }

  return tax;
}

Then:

const federalTax = calcProgressiveTax(taxableIncome, federalBrackets[filingStatus]);
const stateTax = taxableIncome * (stateTaxRate / 100);
const totalTax = federalTax + stateTax;
const effectiveRate = grossIncome > 0 ? totalTax / grossIncome : 0;

Outputs
	•	taxableIncome
	•	federalTax
	•	stateTax
	•	totalTax
	•	effectiveRate

25. Credit Card Payoff Calculator

Inputs
	•	balance
	•	annualAPR
	•	monthlyPayment

Formula

const r = annualAPR / 12 / 100;
let currentBalance = balance;
let months = 0;
let totalInterest = 0;

while (currentBalance > 0 && months < 1200) {
  const interest = currentBalance * r;

  if (monthlyPayment <= interest) {
    throw new Error("Payment too low to ever pay off balance");
  }

  const principal = monthlyPayment - interest;
  currentBalance = Math.max(0, currentBalance - principal);
  totalInterest += interest;
  months++;
}

Outputs

	•	totalInterest
	•	payoffDateEstimate
